# Pavan Reel Studio\n\nBrowser-based kinetic typography editor starter. Static website; no Windows installation or local server needed when deployed.\n\n## Deploy\nPublish the repository root on Vercel, Netlify, or GitHub Pages. No build command is required.\n\n## Features\n- Script-to-scene splitting and editable scene list\n- 9:16, 1:1, 16:9 preview\n- Font, size, color, background and animation controls\n- Per-scene duration, playback and timeline\n- Audio upload and browser playback\n- Export editable project settings as JSON\n\n## Not included yet\nMP4 rendering, AI speech-to-word synchronization, and cloud project storage require a backend/rendering pipeline and are not part of this starter.
